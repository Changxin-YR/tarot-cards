# AppGallery 发布检查清单

## 仓库内已覆盖

- 应用内首次隐私政策与用户协议确认。
- 设置页可再次打开政策与协议全文。
- 核心功能离线，无 `INTERNET` 权限。
- 仅声明振动权限并提供使用原因。
- 塔罗内容明确定位为娱乐、自我反思和情绪整理。
- 高风险健康、安全、法律和投资问题显示专业求助提示。
- API 22 兼容与目标基线保持一致。
- Ability 显式使用 `singleton`，系统启动窗口配置完整。

## 发布者必须人工完成

- [ ] 将 `privacy-policy.md` 托管到公开可访问的 HTTPS 地址，并填写隐私政策 URL。
- [ ] 按发布主体信息补充有效联系渠道。
- [ ] 在 AppGallery Connect 配置 release 签名；不得将口令、私钥或证书秘密提交到仓库。
- [ ] 完成内容年龄分级问卷，按平台最终结果填写，不在代码中伪造分级。
- [ ] 提审说明强调“离线娱乐与自我反思工具”，说明无预测承诺、无付费服务、无网络数据处理。
- [ ] 上传前复核应用图标、截图、应用名称、简介和政策 URL 与当前版本一致。
- [ ] 在目标 phone/tablet 设备或模拟器上完成最终安装、启动、协议确认和核心抽牌流程验收。
