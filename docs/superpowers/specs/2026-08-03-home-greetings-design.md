# 首页分时问候文案设计

## 目标

首页问候区只承担欢迎用户的作用，不再混入“所有问题与记录仅保存在这台设备”等数据保存说明。问候继续依据本地时间切换，不增加联网、定位或持久化依赖。

## 文案

| 时段 | 标题 | 副文案 |
| --- | --- | --- |
| 05:00-08:59 | 早上好 | 新的一天，愿你心怀轻盈与期待 |
| 09:00-11:59 | 上午好 | 愿今天的每一步都从容而清晰 |
| 12:00-13:59 | 中午好 | 忙碌半日，记得让自己稍作休息 |
| 14:00-17:59 | 下午好 | 愿午后的时光温柔而充实 |
| 18:00-21:59 | 晚上好 | 辛苦一天，愿此刻轻松而宁静 |
| 22:00-04:59 | 夜深了 | 愿你卸下疲惫，安心度过今夜 |

## 实现边界

- 保留 `GreetingService.forHour()` 的时段边界与越界小时归一化行为。
- 删除首页问候区对 `privacy_local_only` 的引用，并移除不再使用的字符串资源。
- 不改变首页其他组件、布局间距、本地数据保存规则或隐私机制。

## 验证

- 静态回归测试检查六组完整文案，并确认首页不再引用 `privacy_local_only`。
- Hypium 测试覆盖六个时段边界上的标题和副文案。
- 执行项目标准门禁、debug HAP 与 `entry@ohosTest` HAP 构建。
