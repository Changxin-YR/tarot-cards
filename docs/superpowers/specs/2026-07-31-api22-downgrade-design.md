# HarmonyOS 6.0.2 API 22 降级设计

## 目标

- `compatibleSdkVersion` 与 `targetSdkVersion` 统一为 `6.0.2(22)`。
- 本规格仅在平台版本维度取代第二轮规格与计划中的 API 24 声明，其他产品与设计条款保持有效。
- 保留双主题、四种牌阵、五步抽牌、本地解读、记录、收藏、笔记与设置。
- 不引入网络依赖、登录、权限或新的系统能力。

## 技术策略

- 开发机没有 API 22 SDK，继续使用已安装的 API 24 SDK 作为编译工具链。
- 以目标 API 22 的编译兼容检查为门禁；发现高版本 API 时改用 API 22 可用实现。
- 保留既有 API 24 模拟器验收事实，不将其等同于 API 22 运行验收。

## 验收

- 标准门禁、主题资源校验、应用 HAP 和 ohosTest HAP 构建通过。
- 设备测试保持既有用例通过；当前 API 24 设备只用于向上兼容冒烟。
- API 22 真机或模拟器运行结果在实际观察后才能标记为通过。
